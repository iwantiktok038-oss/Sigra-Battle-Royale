# WANZ XRY BATTLE ROYALE
Prototipe awal game battle royale 3D untuk Godot 4.x.

Fitur awal:
- Arena 3D dengan dinding dan cover.
- Karakter pemain orang ketiga.
- Empat bot yang mengejar pemain.
- Tombol layar: kiri/kanan/maju/mundur, lompat, dan tembak.
- Kontrol keyboard: WASD/arrow, Space, dan F.

Cara membuka:
1. Ekstrak ZIP.
2. Buka folder proyek ini di Godot 4.x.
3. Jalankan `scenes/Main.tscn`.

Catatan: Ini prototipe awal, bukan game Sigma asli atau salinan aset Sigma.
Multiplayer online, loot, zona aman, animasi, dan ekspor APK belum dibuat.
Ekspor Android memerlukan Godot export templates serta Android SDK/JDK yang cocok.
